Data Copilot

Ask a question about a dataset — the copilot generates Python, runs it in a bounded sandbox, self-repairs, verifies, and returns a grounded report.

The loop

Profile dataset→ Generate code→ Guardrail gate→ Execute (sandbox)→ Repair on error→ Verify answer→ Grounded report

Commands

  • copilot.py health — check the LLM endpoint
  • copilot.py profile <data> — dataset schema + stats
  • copilot.py analyze <data> "<question>" — full loop
  • copilot.py audit --limit N — recent runs

Guardrails

  • Bounded execution: timeout, output cap, scoped run dir; no network, no process spawning, no writes outside the run dir.
  • Reports grounded in actual computed output — no invented numbers.
  • Exhausted repair/verify budget ⇒ result labelled UNVERIFIED.
  • Every analysis is appended to the audit trail.
